# Chain of Responsibility Игровой автомат

Описание: Учебное JavaFX-приложение, демонстрирующее паттерн **Chain of Responsibility (Цепочка обязанностей)**. Игровой автомат предлагает пользователю выбрать один из **4 алмазов**. Исход розыгрыша не зависит от выбранного алмаза — обработка одинакова для всех, а поведение задаётся цепочкой обработчиков (выигрыш/проигрыш/шанс/надежда). 

Технологический стек: Java 17+ (совместимый), Maven, JavaFX 17.0.6 (Controls, FXML). Desktop/Standalone GUI.

Статус: учебный демо-проект (Beta).

Ссылка на продукт или демо-экземпляр: локальный запуск через Maven (см. раздел «Установка»).

Отличие от типовых примеров Chain of Responsibility: цепочка используется не «для логирования/валидации», а для геймплейного выбора — каждый обработчик показывает диалог и решает, продолжать ли игру (возвращает boolean), плюс отдельно решается задача начисления выигрыша по последнему типу розыгрыша.

## Архитектура
Ниже перечислены основные сущности (паттерн Chain of Responsibility + точка входа и FXML-контроллер). Пакет `com.example.lab2` в `src/main/java`:

- `Handler` — абстрактный обработчик (пересылает запрос дальше по цепочке).
- `NegativeHandler` — обработка проигрыша (LOSS): диалог «продолжить / отдохнуть».
- `PositiveHandler` — обработка выигрыша (SUCCESS): диалог «играть дальше / забрать».
- `ChanceHandler` — обработка «шанса» (CHANCE): диалог «сыграть бесплатно / отдохнуть».
- `HopeHandler` — обработка «надежды» (HOPE): удерживающее сообщение (игра продолжается).
- `ActionChain` — «розыгрыш»: строит цепочку и генерирует тип события (стратегия удержания).
- `Player` — модель игрока (баланс монет, число сыгранных раундов).
- `HelloController` — связывает FXML, Canvas и игровую логику (Client).
- `HelloApplication` — запуск приложения.

## Зависимости
- JDK: 17+ (совместимый).
- Maven: 3.6+ или Maven Wrapper (`mvnw.cmd`).
- Из `pom.xml`: `javafx-controls`, `javafx-fxml` (OpenJFX 17.0.6) — скачиваются автоматически при сборке.
- Media/звук: не требуется. Визуализация выполнена через **Canvas**.

## Установка
1. Откройте проект в IDE или перейдите в папку проекта.
2. Проверьте, что установлен JDK (подходит 17+).
3. Соберите проект:

```bash
mvnw.cmd clean compile
```

Запуск:

```bash
mvnw.cmd javafx:run
```

Если `mvnw.cmd` пишет `JAVA_HOME not found/invalid`, задайте переменную окружения `JAVA_HOME` на установленный JDK (например `C:\Program Files\Java\jdk-24`) и перезапустите терминал/IDE.

## Применение
После запуска:

- Нажмите **«Кинуть монетку»** — пополнить баланс на 1.
- Нажмите **«Старт»** — игра списывает 1 монету и показывает 4 мешочка.
- Кликните по любому мешочку на Canvas — запускается «розыгрыш» и срабатывает цепочка обработчиков:
  - **SUCCESS (выигрыш)**: можно продолжить игру или забрать выигрыш и выйти.
  - **LOSS (проигрыш)**: можно продолжить игру или выйти.
  - **CHANCE (шанс)**: проигрыш, но можно сыграть бесплатно (компенсация монеты).
  - **HOPE (надежда)**: удерживающее сообщение, игра продолжается.

## Проверка ПО
Автоматические тесты не добавлялись (учебный демонстрационный проект). Проверка выполняется вручную через сценарии: старт без монет, пополнение, старт, клики по мешочкам, выборы в диалогах.

## Проблемы
При запуске из терминала частая причина ошибок — не настроен `JAVA_HOME` или JDK не подхвачен окружением.
